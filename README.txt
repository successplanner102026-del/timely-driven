TIMELY DRIVEN — STATIC WEBSITE STARTER
====================================

What is included
- index.html: homepage and main navigation
- styles.css: responsive styling (warm ivory, navy, orange, sage, white)
- script.js: mobile navigation and copyright year
- used-car-checklist.html: starter car-buying guide
- ownership-costs.html: starter ownership-cost guide
- insurance-basics.html: insurance education page with a disabled future partner CTA
- about.html, privacy.html, affiliate-disclosure.html, contact.html: starter trust/legal pages

IMPORTANT BEFORE GOING LIVE
1. This is a static informational website, not an insurance quote engine. It does not calculate or retrieve real insurance prices.
2. The quote button is intentionally disabled until you have an approved affiliate offer and its correct tracking URL.
3. After MaxBounty approval, verify the campaign's allowed countries, traffic sources, qualification rules, payout, and landing-page restrictions. Then replace the disabled button in insurance-basics.html with an anchor using your approved affiliate URL. Update the homepage CTA if needed.
4. Customize the privacy policy, affiliate disclosure, contact details, and About page to accurately reflect the actual site operator and services. This starter copy is not legal advice.
5. If targeting Quebec, plan a proper French-language version and check applicable language, advertising, privacy, and insurance requirements.
6. Images are loaded from Unsplash URLs and fonts from Google Fonts. They need an internet connection. Check image licensing and consider hosting optimized images locally.
7. The site does not collect quote requests or personal data, and does not include analytics by default. Do not add a form that collects sensitive personal or vehicle information without an appropriate secure service and privacy review.

PREVIEW LOCALLY
- Extract this ZIP.
- Open index.html in your browser.

PUBLISH ON CLOUDFLARE PAGES — DIRECT UPLOAD
1. Sign in to Cloudflare.
2. Open Workers & Pages.
3. Choose Create application > Pages > Get started > Drag and drop your files (dashboard wording can vary).
4. Name the project, for example timely-driven.
5. Upload this ZIP file or the extracted folder contents and deploy.
6. Cloudflare will provide a *.pages.dev address. Open it and test every page and button.

IMPORTANT CLOUDflare CHOICE
Direct Upload is the simplest way to get this static site online, but Cloudflare says a Direct Upload project cannot later be switched to Git integration. If you want automatic deployments from GitHub, create a Git-integrated project from the beginning instead.
